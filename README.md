# 🪙 MediaCoin Bot

Discord-бот для Minecraft-сервера: выдаёт **MediaCoin** за просмотры видео — YouTube и TikTok автоматически. Пользоваться могут только люди, которых владелец сервера добавил в список Media.

## 📖 Инструкция с нуля
👉 **https://magomedovex-code.github.io/mediacoin-bot/**

## ⬇ Скачать
[MediaBot.zip](MediaBot.zip) — все файлы бота. Отдельные файлы — в папке [`bot/`](bot).

## Как работает
1. Владелец сервера: `/addmedia @человек` → бот пишет инструкцию только ему (больше никому).
2. Игрок: `/link Ник` → получает код вида `TOL-4821`.
3. Вставляет код в описание YouTube-видео или подпись TikTok → `/video ссылка`.
4. Раз в час бот смотрит просмотры (YouTube API, TikTok через yt-dlp/страницу видео) и через RCON выдаёт 1 MediaCoin за каждые 100 просмотров (только разницу, без дублей).
