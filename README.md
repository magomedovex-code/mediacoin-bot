# 🪙 MediaCoin Bot

Discord-бот для Minecraft-сервера: выдаёт **MediaCoin** за просмотры видео (YouTube автоматически, TikTok через админа).

## 📖 Инструкция с нуля
👉 **https://magomedovex-code.github.io/mediacoin-bot/**

## ⬇ Скачать
[MediaBot.zip](MediaBot.zip) — все файлы бота. Отдельные файлы — в папке [`bot/`](bot).

## Как работает
1. Игрок: `/link Ник` → получает код вида `TOL-4821`.
2. Вставляет код в описание YouTube-видео → `/video ссылка`.
3. Раз в час бот смотрит просмотры и через RCON выдаёт 1 MediaCoin за каждые 100 просмотров (только разницу, без дублей).
