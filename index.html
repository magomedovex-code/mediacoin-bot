0Как это работает

На сервере есть ранг Media: за каждые 100 просмотров видео (YouTube или TikTok) игрок получает 1 MediaCoin. Бот делает это автоматически:

  1. Владелец Discord-сервера добавляет человека в список Media: /addmedia + его ник в Discord. Бот пишет инструкцию только ему — больше никому.
  2. Игрок пишет боту /link Ник и получает личный код, например TOL-4821.
  3. Вставляет код в описание YouTube-видео или подпись TikTok-видео и пишет /video ссылка.
  4. Бот проверяет, что код есть в описании/подписи, значит видео действительно его.
  5. Раз в час бот смотрит просмотры и через RCON (удалённую консоль сервера) выдаёт монеты.
Защита от обманаОдно видео можно зарегистрировать только один раз. Бот помнит, сколько монет уже выдано за каждое видео, и выдаёт только разницу. Чужое видео (например, MrBeast) не примется — там нет твоего кода. А люди не из списка Media вообще не могут пользоваться ботом.

4Включить RCON на сервере

RCON — это удалённая консоль. Через неё бот отправляет серверу команду give, как будто админ пишет в консоль.

  1. Останови Minecraft-сервер.
  2. Открой файл server.properties (в панели хостинга это обычно «Файлы / File Manager»).
  3. Найди и поменяй эти строки (если их нет — допиши): 
    enable-rcon=true
rcon.port=25575
rcon.password=ПридумайДлинныйПароль123
  4. На хостинге (FalixNodes, Aternos и т.п.) обычно нужно добавить второй порт в разделе «Network / Ports / Сеть». Хостинг выдаст номер, например 21860. Тогда в rcon.port впиши именно этот номер.
    Дома на своём ПК — открой порт 25575 в роутере (port forwarding), если бот будет работать на другом компьютере.
  5. Запусти сервер. В консоли должна появиться строка: 
    RCON running on 0.0.0.0:25575
    (с твоим портом). Значит RCON работает.
Пароль RCON = полный доступ к консолиДелай его длинным и никому не давай. Кто знает пароль — может выполнить любую команду на сервере.
Нет доступа к server.properties или хостинг не даёт второй порт?Ничего страшного — используй ручной режим: бот будет писать админу, кому сколько выдать.

5Проверить RCON

  1. Сервер должен быть запущен.

  3. Впиши адрес сервера (без порта, например play.myserver.net или IP), порт RCON и пароль. Пароль при вводе не виден — это нормально.

    Подключено! Пароль принят.

6Команда выдачи монеты

По умолчанию MediaCoin — это бумага, которая выглядит как командный блок и называется золотым «MediaCoin». Её нельзя поставить на землю, даже в креативе.

Проверь в консоли сервера или в окне теста RCON (без /, ник — свой, ты должен быть онлайн):

minecraft:give ТвойНик paper[item_model="minecraft:command_block",custom_name={text:"MediaCoin",color:"gold",italic:false}] 1

Ответ должен начинаться с Gave 1 [MediaCoin]. Бот смотрит именно на слово Gave.

Почему minecraft: в начале?Плагин Essentials подменяет команду give своей, а она не понимает свойства предмета в [...]. Приставка minecraft: вызывает обычную команду игры.
У меня на сервере уже есть своя монета — как сделать такую же?

Возьми свою монету в руку и введи в чат игры:

/data get entity ТвойНик SelectedItem

Сервер покажет предмет, например {id: "minecraft:command_block", count: 1, components: {"minecraft:custom_name": ...}}. Из этого собирается команда minecraft:give {nick} ПРЕДМЕТ[свойства] {amount}. Если не получается — пришли этот ответ мне (см. Помощь), соберу команду.

У меня монеты — это деньги из плагина экономики

Тогда в settings.txt поставь команду плагина, например для Essentials: GIVE_COMMAND=eco give {nick} {amount}. Но бот ждёт в ответе слово «Gave» — для других команд напиши мне, подстрою.

7Создать Discord-бота

7.1 Приложение и токен

  1. Открой discord.com/developers/applications и войди.
  2. Нажми New Application, назови, например, MediaBot, согласись с правилами → Create.
  3. Слева Bot → Reset Token → Copy. Это токен — пароль бота. Сохрани его, он нужен в шаге 10.
Токен никому не показывай и не отправляй в чаты!С токеном кто угодно может управлять ботом. Если он утёк — сразу Reset Token, старый перестанет работать.
«Privileged Gateway Intents» трогать не нужноБот больше не пишет всем новичкам, поэтому особые разрешения (Server Members Intent) ему не нужны. Если раньше включал — можно оставить.

7.2 Пригласить бота на свой сервер

  1. Слева OAuth2 → URL Generator.
  2. В «Scopes» отметь обе галочки: bot и applications.commands.
  3. Ниже, в «Bot Permissions», отметь: View Channels, Send Messages, Add Reactions, Read Message History.
  4. В самом низу появится ссылка — Copy, открой её в браузере.
  5. Выбери свой сервер → Авторизовать. Бот появится в списке участников (пока «не в сети»).
Галочки пропали после перезагрузки страницы?Это нормально. URL Generator ничего не сохраняет — он только собирает ссылку. Главное — открыть ссылку и добавить бота.

8ID сервера и канала

  1. В Discord: Настройки (шестерёнка внизу) → Расширенные → включи Режим разработчика.
  2. ПКМ по иконке своего сервера слева → Копировать ID сервера. Это GUILD_ID.
  3. Создай закрытый канал для админов, например #media-admin. Туда бот пишет отчёты и заявки.
  4. ПКМ по этому каналу → Копировать ID канала. Это ADMIN_CHANNEL_ID.

9Ключ YouTube (бесплатно)

  1. Открой console.cloud.google.com и войди через Google.
  2. Сверху — выбор проекта → New Project → название mediabot → Create.
  3. В поиске сверху напиши YouTube Data API v3 → открой → Enable.
  4. Слева Credentials → Create credentials → API key → скопируй ключ.
  5. Рекомендуется: нажми на ключ → API restrictions → Restrict key → выбери только YouTube Data API v3 → Save.
Бесплатного лимита хватит с запасом10 000 запросов в день, а бот проверяет до 50 видео за 1 запрос.

11Запуск

  1. Двойной клик по ZAPUSK_BOT.bat.
  2. Первый раз он 1–2 минуты ставит библиотеки discord.py и yt-dlp (для TikTok). Потом при каждом запуске сам обновляет yt-dlp.
  3. Жди строку: 
    Бот запущен как MediaBot#1234. Режим: rcon. TikTok авто: вкл. В списке Media: 0 чел.
  4. Не закрывай это окно — пока оно открыто, бот работает. Свернуть можно.
Строки про PyNaCl и davey«PyNaCl is not installed, voice will NOT be supported» — это про голосовые каналы, они не нужны. Не обращай внимания.
Автозапуск вместе с WindowsWin+R → напиши shell:startup → Enter. В открытую папку положи ярлык на ZAPUSK_BOT.bat (ПКМ по файлу → Создать ярлык → перетащить).

12Список Media — кого добавить

Бот никому не пишет сам. Пользоваться им могут только люди из списка Media, а добавлять туда может только владелец Discord-сервера. Даже другие админы не могут (если владелец не разрешил через MANAGER_IDS).

  1. На своём сервере (в любом канале) напиши /addmedia.
  2. В поле user начни писать ник человека в Discord — появится список, выбери его.
  3. Необязательно: в поле minecraft впиши его ник в игре. Тогда бот сразу привяжет ник и пришлёт человеку личный код.
  4. Нажми Enter. Бот напишет инструкцию только этому человеку в личку.
MediaBotAPP
✅ @Steve добавлен в Media.
Ник Steve_YT привязан, код TOL-2370.
📨 Инструкцию ему отправил.
👁 Это сообщение видишь только ты
КомандаЧто делает
/addmedia user [minecraft]Добавить человека в Media и написать ему инструкцию
/removemedia userУбрать из Media: бот перестаёт принимать его видео и выдавать монеты. Если добавить снова — всё продолжится
/medialistКто сейчас в Media, их ники и сколько видео
Кто пользовался ботом раньшеВсе, кто уже привязал ник в старой версии, автоматически остались в списке Media. Ничего добавлять заново не нужно.
У человека закрыта личка?Бот скажет тебе об этом. Попроси человека самому написать боту /help — или впиши в WELCOME_CHANNEL_ID канал, где бот упомянет только его.

13Как пользуются игроки

Работает только для людей из списка Media. Боту не пишут обычные сообщения — только команды через /. Их можно писать в любом канале сервера или в личке с ботом. Ответы видит только сам игрок.

КомандаЧто делает
/helpПоказывает инструкцию
/link НикПривязывает ник Minecraft и выдаёт личный код (один на всё время)
/video ссылкаРегистрирует видео YouTube или TikTok
/myvideosСписок своих видео: просмотры, выдано, ждёт

YouTube — всё автоматически

  1. /link Ник → бот даёт код, например TOL-2370.
  2. В описание видео добавить код, например в конец:
    Играю на сервере!
TOL-2370
  3. Подождать минуту, потом /video https://youtube.com/shorts/...
  4. Быть онлайн на сервере — монеты придут при ближайшей проверке.
MediaBotAPP
✅ Видео Мой лучший клип принято!
Сейчас 17640 просмотров → положено 176 MediaCoin.
Монеты придут при следующей проверке (раз в 60 мин), когда ты будешь онлайн.
👁 Это сообщение видишь только ты

TikTok — тоже автоматически

  1. Вставить код в подпись TikTok-видео (при публикации или потом: … → Изменить).
  2. Скопировать ссылку на видео (Поделиться → Копировать ссылку). Подходят и короткие vm.tiktok.com/…, и полные.
  3. /video ссылка — бот сам откроет видео, найдёт код в подписи и запомнит просмотры.
  4. Дальше раз в час бот обновляет просмотры TikTok так же, как YouTube.
Если TikTok не пустил ботаУ TikTok нет бесплатного API для просмотров, поэтому бот читает их со страницы видео, как браузер. Иногда TikTok это блокирует (капча). Тогда видео всё равно сохраняется, бот пробует ещё раз при следующей проверке, а админам приходит заявка — они могут вписать просмотры вручную через /setviews. Если не читается вообще ни одно видео — перезапусти бота: он обновит yt-dlp.
Игрок не в сети или сервер спит?Монеты не пропадают. Бот выдаст их при следующей проверке, когда игрок будет онлайн. Если инвентарь полный — монеты упадут рядом.

15Без RCON — ручной режим

Если нет доступа к RCON (хостинг не даёт порт, сервер не твой и т.п.):

  1. В settings.txt поставь MODE=manual. RCON-строки можно не заполнять.
  2. Обязательно укажи ADMIN_CHANNEL_ID.
  3. Бот будет писать в админ-канал: «Ник положено X MediaCoin» и готовую команду.
  4. Админ выдаёт монеты в игре и ставит реакцию ✅ под сообщением — бот запомнит, что выдано.

16Бот 24/7 онлайн

На твоём ПК бот работает, только пока ПК включён и окно открыто. Чтобы он работал всегда, его переносят на хостинг — компьютер в интернете, который не выключается.

🆓 Бесплатный хостинг для ботов

В интернете есть бесплатные хостинги для Discord-ботов 24/7. Найди в Google: free discord bot hosting python. Выбирай такой, где:

  • поддерживается Python;
  • можно загрузить свои файлы;
  • бот не засыпает (читай условия);
  • файлы сохраняются после перезапуска.
💶 Недорогой VPS

Самый надёжный вариант: свой маленький сервер в интернете за несколько евро в месяц. Подходит, когда бот нужен для настоящего большого сервера.

Как перенести бота на хостинг

  1. Загрузи файлы: bot.py, rcon_client.py, settings.txt, requirements.txt. Файлы .bat там не нужны.
  2. Если бот уже работал на ПК — загрузи и mediacoin.db (база, кто что получил).
  3. Команда запуска на хостинге: python bot.py (или выбери bot.py как главный файл). Библиотеки (discord.py, yt-dlp) ставятся из requirements.txt.
  4. Выключи бота на ПК! Два бота с одним токеном мешают друг другу (ошибка «session has been invalidated»).
Осторожно с бесплатными хостингамиТы загружаешь туда токен и пароль RCON. Используй известные сервисы с хорошими отзывами. Если сомневаешься — сделай Reset Token после переезда на другой хостинг.

Добавлять в Media может только владелец сервераТак и задумано. Если нужно разрешить кому-то ещё — впиши его Discord ID в MANAGER_IDS и перезапусти бота.
Нет /addmedia после /Видна только тем, у кого право «Администратор». Перезапусти бота и нажми Ctrl+R в Discord.
session has been invalidated много раз подрядБот запущен в двух местах (ПК + хостинг или два окна). Запусти STOP_BOT.bat, выключи бота на хостинге. Не помогло — Reset Token и новый токен в settings.txt.
Бот УЖЕ запущен на этом компьютереОткрыто второе окно. Закрой лишнее или STOP_BOT.bat.
Время ожидания вышло / нет связи с серверомСервер выключен или спит; порт RCON не открыт или неверный (шаг 4).
Соединение отклоненоrcon.port и порт в панели хостинга не совпадают.
Неверный пароль RCONСравни с rcon.password в server.properties (без пробелов в конце).
Команд нет после /Бот должен быть запущен. Нажми Ctrl+R в Discord. В личке команды иногда появляются через пару минут.
В описании видео нет твоего кодаДобавь код в описание (не в комментарий), подожди минуту и повтори.
В подписи TikTok-видео нет твоего кодаКод должен быть в подписи видео (не в комментарии и не в профиле). Измени подпись, подожди пару минут и повтори.
«Не могу прочитать просмотры TikTok… 3 раза подряд» (в админ-канале)TikTok блокирует бота. Перезапусти бота (обновится yt-dlp), а пока впиши просмотры вручную: /setviews.
Видео принято, но монет нетПроверка раз в час. Зайди на сервер и попроси админа сделать /checknow.
сервер ответил: Unknown or incomplete commandОшибка в GIVE_COMMAND. Проверь команду в консоли (шаг 6), не забудь minecraft:.
